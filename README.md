# Chess Desktop Game

A complete local chess application built with Python and Tkinter.

## Play

Double-click `launch_chess.bat`, or run:

```powershell
py chess_game.py
```

## Features

- Two-player local mode
- Player versus computer mode with a minimax chess AI
- Legal move highlighting
- Check, checkmate, and stalemate detection
- Castling, en passant, and pawn promotion
- Move history, undo, board flipping, and new game controls

## Test

```powershell
py test_chess_game.py
```
